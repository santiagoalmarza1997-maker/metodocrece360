# Método Crece 360®

Landing page oficial de **Método Crece 360®** para agentes inmobiliarios.

## Despliegue en Vercel
Este repositorio está estructurado y optimizado para desplegarse con un solo clic en [Vercel](https://vercel.com):
- `index.html`: Landing page con diseño editorial de ultra-lujo, Hero orgánico en dos tonos y tarjetas flotantes.
- `assets_crece360/`: Activos visuales y fotografías en alta definición.
- `vercel.json`: Optimización de URLs limpias y caché para máxima velocidad de carga.
